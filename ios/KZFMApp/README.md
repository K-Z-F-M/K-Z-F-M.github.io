# KZFM iOS App

This folder contains a minimal SwiftUI app wrapper for the KZFM portfolio website.

What it does:
- Loads the GitHub Pages site in a WebView
- Includes back, forward, refresh, and Safari actions
- Provides a native iOS shell for the webpage

How to use:
1. Open Xcode
2. Create a new iOS App project
3. Add these files into the project
4. Set the app bundle identifier and signing config
5. Run on a simulator or a real device

Website URL used by default:
https://k-z-f-m.github.io

If you want this to use a different page or a local HTML file, update the URL in `ContentView.swift`.
